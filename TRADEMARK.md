# Trademark status of the name "ColdReach"

**The name ColdReach is a working name only. No trademark
clearance search has been performed for this project, by anyone,
as of the Phase 6 release (version 1.1.0).** Nothing in this
repository, the product UI, or any project document claims or
implies that the name is available, registrable, or safe to build
a public brand on. Do not print it on anything permanent, register
social handles as a brand launch, or buy long-term assets in this
name until the checks below are done.

This file is a checklist for the owner (or their counsel), not
legal advice and not a substitute for a professional search.

## What a real clearance check requires

- [ ] **USPTO search (United States).** Search the USPTO trademark
      database (TESS, now Trademark Search at tmsearch.uspto.gov)
      for "ColdReach" and close variants ("Cold Reach") in the
      relevant classes, at minimum International Class 42
      (software as a service) and Class 35 (advertising and
      business services), plus a scan of live applications, not
      only registrations. Note any confusingly similar marks owned
      by email, CRM, or sales software companies.
- [ ] **EUIPO search (European Union).** Search the EUIPO eSearch
      database for identical and similar marks in the same classes
      if the product will be marketed to EU customers.
- [ ] **IPO Pakistan search.** Search the Intellectual Property
      Organization of Pakistan trademark register (online journal
      and register search, or in person) for identical and similar
      marks, since the operating business is based in Pakistan.
- [ ] **Common-law and market scan.** Search the web, app stores,
      Product Hunt, and domain and social handle availability for
      existing businesses already trading as ColdReach or Cold
      Reach in software or sales tooling. An unregistered but
      active user can still block or dilute a launch.
- [ ] **Domain check.** Confirm the intended domain (for example a
      .com) is available and not itself infringing a mark found
      above, before purchase.
- [ ] **Professional review.** Have a trademark attorney, or at
      minimum a professional search firm, review the results and
      give a written registrability opinion in each jurisdiction
      you plan to sell in. A keyword search by a non-lawyer is a
      screening step, never a clearance.
- [ ] **Decision record.** Write the outcome here when it exists:
      cleared, cleared with risks, or name change required, with
      the date and who performed the check. If the name changes,
      update the plan catalog labels, UI branding, ACTIVATION.md,
      and this file in the same change.

## Until then

- Keep referring to ColdReach as a working name in launch
  documents.
- The custom domain procedure in DEPLOYMENT.md should only be
  executed for a domain the owner is comfortable rebranding away
  from, or after the decision record above exists.
